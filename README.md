### Featured Projects

**[Explainable Financial Fraud Detection](https://github.com/KSKeerthivasan/Fraud-Detection)**
End-to-end credit-card fraud detection pipeline — XGBoost with SMOTE + Stratified K-Fold CV, a FastAPI inference service with Bayesian probability recalibration, a Streamlit dashboard, and SHAP-based explainability. Dockerized, with CI via GitHub Actions.
`Python` `XGBoost` `FastAPI` `Docker` `Streamlit` `SHAP` — **85.2% F1** · **98.2% ROC-AUC**

**[GroqCloud Integration — Corsair](https://github.com/corsairdev/corsair/pull/877)** · merged
Integration plugin adding GroqCloud support: audio transcription/translation, chat completion, model listing, and TTS voice listing, with Zod validation, rate-limit handling, and automated tests.

**[Studio by AI21 Labs Integration — Corsair](https://github.com/corsairdev/corsair/pull/918)** · merged
Integration plugin for AI21's Studio API — chat completions, library file management, and Maestro run creation/retrieval, with typed schemas and 17/17 passing tests.

**[Rate Limits & Budget Constraints — Corsair](https://github.com/corsairdev/corsair/pull/937)**
Added global, per-tenant, and per-plugin usage limits with time-windowed quotas and atomic usage counters at the permission/integration layer, with full test coverage.
